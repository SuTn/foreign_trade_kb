# AI需求汇总归整

## 需求优先级说明

| 优先级 | 说明 |
|:---|:---|
| **P0** | 核心刚需：业务强依赖、直接解决核心痛点，第一期必须上线 |
| **P1** | 重要提效：显著降低人工成本、提升转化，第二期落地 |
| **P2** | 远期迭代：高阶能力与体验优化，后续版本规划 |

---

## 一、客户全生命周期管理

| 功能名称 | 优先级 | 用户故事 | 功能说明与AI落地要点 |
|:---|:---|:---|:---|
| 客户自动分层标签体系 | P0 | 作为业务员，我希望系统自动按意向程度给客户划分等级，以便我针对性制定跟进策略 | 基于NLP语义分析+消息行为数据，自动将客户划分为已购客户、意向A/B/C/D类；自动按国家/地区、渠道来源打标签，支持每日询盘量按国家维度统计汇总 |
| 客户信息档案管理 | P0 | 作为业务员，我希望客户基础信息能自动留存并支持备注，以便我快速掌握客户全貌 | 支持人工录入备注（姓名、地区、联系方式、常购车型）；大模型自动从聊天记录中抽取意向车型、预算、采购量等字段回填档案，形成360°客户卡片 |
| 分级跟进提醒与公海流转 | P0 | 作为业务员，我希望系统按客户等级自动推送跟进提醒，长期未回复的客户自动进入公海，以便我高效管理跟进节奏、盘活沉睡客户 | 按规则自动推送提醒：A类每日1次、B类1-2天1次、C/D类3天1次；C/D类客户15天无有效回复自动收回公共客户池；支持业务员自行领取公海客户二次激活，配置领取防重复与冷却期规则 |
| 新增询盘智能分级 | P0 | 作为业务员，我希望新询盘能自动区分质量等级，以便我优先处理高意向客户 | 构建询盘质量评分模型，从身份真实性、信息完整度、采购意向强度等维度，自动划分为高意向/普通/垃圾询盘，高意向询盘置顶优先分配 |
| 客户公开信息智能背调 | P1 | 作为业务员，我希望系统能基于客户公开主页信息生成背调报告，以便我辅助判断客户实力 | 基于客户社媒主页、公开工商信息等合规数据源，自动聚合客户企业规模、主营业务、历史采购线索，输出客户画像报告 |
| 客户意向动态更新 | P1 | 作为业务员，我希望客户意向等级能随沟通深度自动变化，以便我及时调整跟进优先级 | 实时识别对话中的强意向信号（确认车型、议价、索要单证、约定看车），自动升级客户等级与提醒频率；长期无互动自动降级 |

## 二、多语种智能沟通与知识应答

| 功能名称 | 优先级 | 用户故事 | 功能说明与AI落地要点 |
|:---|:---|:---|:---|
| 场景化多语种话术生成 | P0 | 作为业务员，我希望针对不同业务场景一键生成俄语/英语专业回复，以便我快速答复客户且贴合当地表达习惯 | 内置汽车外贸领域术语库，自动识别询价、砍价、看车、物流、付款、售后6类场景；生成俄语/英语双版本话术，支持邮件正式体、社媒口语体两种风格，可一键润色现有消息 |
| 历史对话智能摘要 | P0 | 作为业务员，我希望系统自动提炼客户聊天核心信息，以便我不用翻大量记录就能快速复盘 | 采用抽取+生成式摘要算法，结构化输出：意向车型、预算区间、目标国家、核心顾虑、待跟进事项，支持按时间/场景筛选查看 |
| 业务高频问题智能问答 | P0 | 作为业务员，我希望二手车车况、报关、关税、MOQ、质保等高频问题能自动生成标准答案，以便我答复统一且准确 | 基于RAG技术搭建业务FAQ库，覆盖二手车出口全链路高频问题；答复口径统一可管控，支持持续沉淀新问答对 |
| 库存报价知识库应答 | P0 | 作为业务员，我希望AI能直接基于公司库存和报价政策答复客户询价，以便我不用反复查库存表 | 对接内部库存、报价、物流政策数据库，数据实时同步；AI理解客户询价需求后自动检索对应车型、价格、物流方案，生成完整询价回复 |
| 实时聊天智能回复辅助 | P1 | 作为业务员，我希望聊天时侧边栏自动给出回复建议，以便我提升回复效率 | 聊天界面侧边栏实时推送3套备选回复，支持一键发送/修改后发送；自动识别小语种消息并实时翻译为中文 |
| 客户消息情绪与风险识别 | P1 | 作为业务员，我希望客户的不满、投诉、异常诉求能被高亮提醒，以便我及时处理风险 | 自动识别客户消息情绪与诉求等级，对投诉、大额异议、异常付款要求等关键信号做高亮预警 |

## 三、报价与谈判

|:---|:---|:---|:---|
| 一键成本报价计算器 | P0 | 作为业务员，我希望输入车型和目的地就能自动算出总成本与报价，以便我快速给客户报价且不出错 | 内置车价、报关费、运输费、保险、关税、服务费全链路成本模型；支持按贸易术语（EXW/FOB/CIF等）自动核算，输出总成本、建议售价与利润明细，支持多方案对比 |

| 贸易术语自动讲解 | P1 | 作为业务员，我希望客户问到贸易术语时能自动生成通俗解释，以便我清晰传递权责划分 | 自动识别对话中提及的贸易术语，生成对应语种的权责划分、费用构成、风险边界说明，可直接发送给客户 |
