# AI 需求分析：现有底座可扩展的 P0 优化

> 基于 `docs/AI需求汇总归整.md`，聚焦**现有系统可直接扩展的 P0 需求**。
> 不涉及库存/订单/报价/物流等外部数据源（需另行建设）。

## 一、范围界定

从需求文档 P0 中筛选出**现有底座可直接扩展**的 3 个方向：

| # | 方向 | 对应需求 | 现有基础 |
|:--|:-----|:---------|:---------|
| 1 | 客户自动分层标签体系 | 客户自动分层标签体系 | `profiles` 表 + `deal_stage` 字段 |
| 2 | 历史对话智能摘要 | 历史对话智能摘要 | `build_chat_summary` 简单拼接 |
| 3 | 多语种话术生成 | 场景化多语种话术生成 | `reply/generator.py` 风格变体 |

**明确不做（需外部数据源）**：库存报价/成本核算/车龄排放合规/订单流转/物流方案/社媒获客/合同生成/财务单据校验等。

**暂缓**：每日业务数据汇总（需进一步调研业务口径后再定）。

## 二、依赖关系与排期

```
方向1 客户分层（独立）
方向2 对话摘要（独立）
方向3 多语种话术（独立）
```

三个方向相互独立，可并行或按序实施。**建议排期**：方向1 → 方向2 → 方向3。

## 三、已确认决策

| 决策项 | 结论 |
|:-------|:-----|
| 分层标准 | 先定义**初版规则**（LLM 按规则判定 A/B/C/D），后续可迭代 |
| 摘要粒度 | **按客户聚合**（汇总该客户全部会话） |
| 多语种范围 | **汉语、英语、俄语** |
| 每日日报 | **本期不做**，需再调研业务口径 |

## 三、各方向设计要点

### 方向 1：客户自动分层标签体系（P0）

**目标**：LLM 按初版规则自动将客户划分为 A/B/C/D 级并打标签，业务员可手动调整覆盖。

**现状**：
- `profiles` 表为 key-value（`customer_id, field, value, source, updated_at`）
- `upsert_profile_field` 已支持 `source=manual` 不被 `auto` 覆盖（`sqlite_store.py:60`）
- `extractor.py` 已抽取 `deal_stage` 字段，但为自由文本

**初版分层规则（草案）**：
- **A 类（高意向）**：明确确认车型/议价/索要单证/约定看车/谈付款
- **B 类（中意向）**：详细询价/多次沟通/询问物流与交期
- **C 类（低意向）**：一般询价/简单咨询/信息收集
- **D 类（无效/沉睡）**：垃圾询盘/长期无回复/无明确需求

**设计**：
- 扩展 `extractor.py` 的 prompt，让 LLM 按上述规则输出结构化字段：
  - `intent_level`：A/B/C/D
  - `tags`：逗号分隔的业务标签（如：已购、意向车型、议价中、待跟进）
- 复用 `upsert_profile_field` 的 manual 保护机制（人工改后 auto 不覆盖）
- 前端 `customers.html` 增加等级筛选/排序、标签展示

**改动文件**：`extractor.py`、`customers.html`、`profile_list.html`、相关测试

### 方向 2：历史对话智能摘要（P0）

**目标**：按客户聚合自动提炼聊天核心信息，结构化输出意向车型/预算区间/目标国家/核心顾虑/待跟进事项。

**现状**：`build_chat_summary` 仅把消息拼接成文本，无结构化。

**设计**：
- 新增摘要生成模块（`profile/summarizer.py`），LLM 输出结构化 JSON
- **按客户聚合**：汇总该客户全部关联会话（复用 `build_customer_summary`）
- 新增存储表 `customer_summaries`（`customer_id, 结构化字段, updated_at`）
- 前端客户详情页展示摘要

**改动**：新增 `summarizer.py`、schema 加表、`chat.html` 展示、相关测试

### 方向 3：多语种话术生成（P0）

**目标**：针对不同业务场景一键生成**汉语/英语/俄语**专业回复。

**现状**：`reply/generator.py` 仅支持 4 种风格变体（default/concise/warm/formal），无语种、无场景识别。

**设计**：
- 扩展 `generator.py`：新增场景识别（询价/砍价/看车/物流/付款/售后）+ 语种（中/英/俄）+ 风格
- 前端聊天页增加语种/场景选择
- 复用现有 RAG 召回 + 异步任务机制

**改动**：`generator.py`、`chat.html`、`reply_result.html`、测试
