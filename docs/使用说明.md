# 外贸客户知识库 · 小白使用说明

> 这是一份给**完全没接触过本系统**的业务员/普通用户看的操作手册。
> 你不需要懂代码、不需要懂数据库，只要会打开浏览器、会点鼠标，就能用起来。

---

## 一、这个系统是干什么的？

一句话：**它把你的 WhatsApp 客户聊天记录自动同步到本地，然后用 AI 帮你分析客户、写回复。**

具体能帮你做三件事：

1. **自动同步聊天** —— 你正常用 WhatsApp 和客户聊天，系统在后台悄悄把聊天记录存到本地电脑（只读，不会替你发消息）。
2. **自动分析客户** —— 系统会从聊天里提取客户信息（公司、国家、意向车型、预算等），并给客户打上「意向等级」（A/B/C/D）。
3. **帮你写回复** —— 客户发来消息，你点一下「生成回复」，AI 会结合这个客户的历史聊天 + 你的产品知识库，给你一段建议回复，你复制后手动发出去。

> ⚠️ **重要**：系统**不会自动发消息**。所有回复都是「建议」，最终由你复制到 WhatsApp 手动发送。

## 二、第一次使用（安装 + 启动）

> 如果你已经由技术人员装好并启动，直接跳到「三、日常使用」。

### 2.1 需要准备什么

- 一台电脑（Windows / Mac / Linux 都行）
- 电脑上装了 **Python 3.11 或更高版本**
- 一个 **WhatsApp 账号**（建议先用小号/备用号试跑，见文末风险提示）
- 一个 **AI 接口的 Key**（用于生成回复和分析，如 OpenAI / DeepSeek / Anthropic）

### 2.2 安装步骤

打开终端（Windows 用 PowerShell，Mac 用「终端」），进入项目文件夹后依次执行：

```bash
# 1. 创建虚拟环境（推荐用 uv，没有就装一个）
uv venv .venv
source .venv/bin/activate        # Windows 用: .venv\Scripts\activate

# 2. 安装依赖
uv pip install -e ".[dev]"

# 3. 安装浏览器组件（用于打开 WhatsApp Web）
playwright install chromium

# 4. 复制配置示例
cp .env.example .env
```

### 2.3 配置 AI 接口（关键一步）

用记事本打开项目里的 `.env` 文件，找到这几行，填上你的 AI 接口信息：

```dotenv
# 用 DeepSeek 的话（国内常用，便宜）：
KB_LLM_PROVIDER=openai
KB_LLM_MODEL=deepseek-chat
KB_LLM_API_BASE=https://api.deepseek.com/v1
KB_LLM_API_KEY=sk-你的密钥

# 用 OpenAI 的话：
# KB_LLM_PROVIDER=openai
# KB_LLM_MODEL=gpt-4o
# KB_LLM_API_BASE=https://api.openai.com/v1
# KB_LLM_API_KEY=sk-你的密钥
```

> 💡 **嵌入（向量化）和重排模型默认用本地模型，首次会自动下载，不用你管。**
> 如果下载很慢或失败，可以改用在线接口，见项目根目录 `README.md` 的「配置」章节。

### 2.4 启动

```bash
python -m app
```

启动后会发生两件事：

1. **弹出一个 Chrome 窗口**，打开 WhatsApp Web —— 用手机扫码登录（只需第一次，之后自动记住登录状态）。
2. 浏览器访问 **http://127.0.0.1:8000** 就能看到系统界面了。

> 首次登录后，系统会开始自动同步聊天记录。**等几分钟**，客户列表里就会慢慢出现你的客户。

## 三、日常使用（核心流程）

### 3.1 看客户、回消息（工作台）

点顶部「**客户**」，进入三栏工作台：

```
┌─────────────┬──────────────────┬──────────────────┐
│  左栏：客户列表 │   中栏：聊天窗口    │  右栏：画像 + AI  │
│  （搜索/筛选）  │  （看消息、生成回复） │  （分析、建议）    │
└─────────────┴──────────────────┴──────────────────┘
```

**左栏 —— 客户列表**
- 每个客户显示：头像、名字、公司/国家、最近消息时间、未读消息数。
- 顶部有搜索框（按名字/电话/公司搜）和等级筛选（A/B/C/D/未分层）。
- 客户按「最近活跃」排序，谁最近有消息谁排前面。

**中栏 —— 聊天窗口**
- 点左栏某个客户，这里就显示和 TA 的聊天记录。
- 新消息会**自动刷新**（每 5 秒检查一次），不用手动刷新页面。
- 如果这个客户有多个会话（比如私聊 + 群聊），顶部会有标签页可以切换。
- 默认显示最近 50 条消息；想看更早的，点聊天区顶部的「**加载更早消息**」。

**右栏 —— 画像 + AI 建议**
- 点客户后自动加载，有三个标签页：
  - **画像**：这个客户的意向等级、标签、画像字段（可手动编辑）。
  - **摘要**：AI 生成的对话摘要（意向车型、预算、目标国家、顾虑、待跟进事项）。
  - **AI 建议**：跟进建议 + 客户分析。

### 3.2 生成回复（核心功能）

在聊天窗口里，每条客户消息旁边都有「**回复**」按钮：

1. 点某条消息的「**回复**」，底部会弹出回复面板，显示你要回复的那条消息。
2. 在面板里选一下回复偏好（可选）：
   - **语种**：中文 / English / Русский
   - **场景**：询价 / 砍价 / 看车 / 物流 / 付款 / 售后
   - **语气**：口语 / 正式
3. 点「**生成回复**」，等几秒，AI 会给出建议回复。
4. 点「**复制**」，然后**回到 WhatsApp 手动粘贴发送**。

> 想换个说法？点「重新生成」，AI 会用不同风格再写一版。

### 3.3 看客户分析（AI 建议）

在右栏「AI 建议」标签页：
- **生成跟进建议**：AI 告诉你这个客户该不该跟进、下一步做什么、什么时候联系、怎么说。
- **生成客户分析**：AI 分析客户的兴趣点、活跃度、跟进建议。

### 3.4 手动编辑客户画像

在右栏「画像」标签页，你可以：
- 修改**意向等级**（A/B/C/D）。
- 编辑**标签**（逗号分隔）。
- 新增/修改**画像字段**（比如公司、国家、预算等）。

> 你手动改的内容，AI 之后不会覆盖（人工优先）。

## 四、知识库（让 AI 更懂你的产品）

AI 写回复时，会参考你上传的**产品资料/报价单/常见问题**，这样回复更专业。

1. 点顶部「**知识库**」。
2. 点「选择文件」选一个文档（支持 PDF / Word / Excel / CSV / HTML / Markdown / 纯文本）。
3. 在「文件名」框里填上文件名（含扩展名，如 `产品手册.pdf`）。
4. 点「**上传**」，系统自动解析、建立索引。
5. 上传后，AI 写回复时就会参考这些资料。

> 想测试检索效果？在页面下方「检索测试」输入一句话，看系统能不能找到相关片段。

### 导出 Obsidian 笔记

点「**导出 Vault**」，系统会把知识库整理成 Obsidian 笔记库（在 `data/vault/` 文件夹），可以用 Obsidian 软件打开浏览。

## 五、全局搜索

点顶部「**搜索**」，输入关键词，系统会同时搜：
- 客户（名字/电话/公司/国家）
- 聊天记录
- 知识库文档
- 客户画像字段

输入即搜，不用按回车。

## 六、数据清理（谨慎使用）

点顶部「**清理**」，可以删除聊天记录（**删除不可恢复！**）：
- **按会话清理**：需要填 `chat_id`（一串技术编号，一般用户用不到）。
- **按天数清理**：填天数，删除 N 天前的所有消息。

> ⚠️ 清理只删聊天消息，**不会删客户画像和知识库**。但删了就找不回来，请谨慎。

---

## 七、设置（一般不用动）

点顶部「**设置**」，可以调整采集器的同步参数：
- **同步频次**：多久检查一次新消息（默认 2 秒，一般不用改）。
- **自动扫描**：是否自动逐个打开会话读取全部聊天（默认开启，每 10 分钟一次）。

> 这些参数保存后立即生效，不用重启。**新手建议保持默认。**

## 八、常见问题（FAQ）

**Q1：启动后 Chrome 没弹出来 / 没打开 WhatsApp？**
检查是否已执行 `playwright install chromium`，并确认 `.env` 没改坏。

**Q2：客户列表是空的？**
刚启动需要时间同步。等几分钟，或点首页的「立即全量扫描」手动触发一次。

**Q3：点「生成回复」一直转圈？**
可能是 AI 接口没配好（检查 `.env` 的 `KB_LLM_API_KEY`），或模型还在下载。看首页「采集器状态」是否在线。

**Q4：回复是英文/俄文，我想要中文？**
生成前在「语种」下拉里选「中文」。

**Q5：数据存在哪？会不会上传到云端？**
所有数据都存在你电脑的 `data/` 文件夹，**不上云**。备份时把这个文件夹拷走即可。

## 九、数据备份

所有数据都在项目根目录的 `data/` 文件夹里，包括：
- `kb.db` —— 客户、聊天、画像、知识库（SQLite 数据库）
- `chroma/` —— 向量索引
- `user-data-dir/` —— WhatsApp 登录状态
- `vault/` —— 导出的 Obsidian 笔记

**备份 = 把 `data/` 文件夹整个复制一份。**

## ⚠️ 十、风险提示（务必阅读）

本系统通过自动化方式访问 WhatsApp Web，属于**非官方客户端**，**有封号风险**。虽然系统设计为「只读 + 低频 + 持久登录」来尽量降低风险，但风险无法完全消除。

**强烈建议：**
- 先用**小号/备用号**试跑几天，确认没问题再用主号。
- 不要用主账号直接跑。
- 定期备份 `data/` 文件夹。
