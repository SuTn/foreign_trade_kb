# WhatsApp 封号风险提示

## 风险

本项目通过 CDP 自动化访问 WhatsApp Web, 属非官方客户端, 违反 WhatsApp ToS, **有封号风险**。
根本风险无法消除, 实际概率在"只读 + 持久登录 + 低频 + 抖动"下属较低但非零。

## 降低风险措施

- **全程只读** (`ReadOnlyCDP` 门面, 不发送任何消息)
- **持久登录** (`user-data-dir`, 不重复扫码)
- **低频轮询 + 随机抖动** (fast/slow tick + jitter)
- **单设备单账号**

## 建议

- 用小号/备用号试跑, 勿用主账号
- 先小规模试跑几天观察
- 定期导出知识库备份 (`data/` 目录)
